设为默认播放器

桌面程序会打开 Windows 的“默认应用”页面。此浏览器原型只展示正确的引导流程，不会修改系统设置。

1在默认应用页面搜索“实时字幕播放器”。
2依次确认 MP4、MKV、AVI、MOV 等视频类型。
3返回播放器后即可从右键“打开方式”直接启动。
