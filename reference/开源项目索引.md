## 对当前项目的参考价值（已验证的对照结论）

### mpv-examples + mpc-qt —— libmpv 集成的"标准答案"

我们踩过的三个深坑，两者生产代码都给出了相同答案（2026-08-30 已比对源码）：

1. **paintGL 目标 FBO 必须是 `defaultFramebufferObject()`**：
   `mpv-examples/libmpv/qt_opengl/mpvwidget.cpp:79`、`mpc-qt/src/mpvwidget.cpp:1150`
   ——我们曾传 `fbo.fbo=0` 导致永久黑屏（questions/libmpv播放停滞排查指南.md 根因 6）。
2. **渲染尺寸用物理像素（DPR 缩放）**：
   `mpc-qt/src/mpvwidget.cpp:1161-1163` `glWidth = qRound(w * devicePixelRatioF())`
   ——与我们的 `width() * devicePixelRatioF()` 一致。
3. **update 回调 → maybeUpdate 模式 + 最小化手动绘制兜底**：
   `mpv-examples .../mpvwidget.cpp:128-150`——防止 Qt 跳过隐藏窗口重绘导致
   mpv render API 超时卡顿（我们的根因 7 修复同款）。

**经验**：libmpv + Qt 集成的任何疑难，先查这两个仓库的 `mpvwidget`/`MpvGlWidget`
再动手；官方头文件注释（render.h Threading 节）是第二信息源。

### mpc-qt —— 产品级播放器的交互基线

- 播放列表/播放历史/收藏的目录组织、快进快退键位、OSD 提示分层，
  可作为我们 P7 UI 复刻之外"参考稿没画到"部分的对照基线。
- `src/thumbnailerwindow.cpp`：进度条缩略图预览的独立窗口实现（后续增强参考）。

### QMPlay2 —— 模块化后端与打包

- 多后端抽象（libmpv 只是可选模块之一）：我们单绑 libmpv，但其
  AudioFilters/字幕模块的边界处理可借鉴。
- Windows 打包（安装器/便携版双轨）可对照 packaging/。

### buzz —— 实时转写产品的 UX 对照

- 转写结果面板的分段/时间戳/导出交互，与我们转写面板同构，可对照打磨。
- 实时录音转写的分段节奏（句子切分粒度）与我们 VAD 分句策略互为参照。
