# 前端像素复刻排查指南

> 适用问题类型：Qt Widgets 前端与 `05_Single_HTML_Frontend_Reference.html` / `04_UI_Design_Mockup.png` 的逐像素对齐差异排查。
> 更新记录见文末。

## 问题描述

把 `src/player/`（MainWindow.cpp + UiKit.h）的 Qt Widgets UI 做到与参考 HTML 设计稿「同尺寸并排比对无可见差异」。参考稿为 1280x800 的 showcase 页面：顶部 `.app-window` 是应用窗口（宽 1280，高约 615px），底部是特性卡区（复刻范围外）。

## 已建立的有效方法（✅）

- ✅ 截图机制：`RCP_DEMO_ONLY=1` + `RCP_SNAPSHOT=<png>` + `RCP_SNAP_T1/T2` 抓 1280x800 逻辑界面；`RCP_NO_CAPTION=1` 跳过 worker。脚本 `tools/run_snap.ps1`。
- ✅ 参考渲染：Edge 无头渲染参考 HTML 到 1280x800。**失败尝试 ❌**：`--headless=new --virtual-time-budget=8000` 在 PowerShell 下超时未出图（进程挂起）。**成功方法 ✅**：复用上一轮已生成的 `out/e2e-verify/ref-1280.png`（HTML 未变化，渲染结果一致）；如需重渲改用 `--headless=old` 或带超时并确认进程退出。
- ✅ 缩放对齐：应用快照 1920x1200（150% DPI）用 PIL LANCZOS 缩到 1280x800，再按参考稿布局列宽（1280 断点：左轨 218 / 视频区 218-958 / 设置面板 958-1280）裁剪各区域并排（ref 左 / ours 右），脚本 `tools/make_compare.py`、`tools/compare_regions.py`、`tools/compare_deck2.py`、`tools/zoom_regions.py`。
- ✅ 像素级确认：PIL 采样目标行/区域的精确颜色与字形高度，判断图标有无、字体大小、滑块颜色等（OCR 描述不可尽信）。
- ✅ 差异清单逐项修复后，重新 `tools/run_snap.ps1` 出图 → 重新并排比对 → 清零才算 DONE。

## 关键认知（避免重复踩坑）

1. **参考稿 1280 断点**：`@media (max-width:1320px)` 下左轨 238→218、设置面板 344→322、标题动作按钮隐藏文字标签只留图标。应用 `applyBreakpoint()` 已实现，比对/裁剪必须按断点后的列宽来。
2. **应用窗口高度 vs 参考 app-window 高度不同**：参考 app-window 仅约 615px（下方是 showcase 特性卡区），实际应用窗口是完整 800px。因此视频区/转写区/左轨底部更高，控制条在 y≈692（参考在 y≈507）。这是固有差异，不修；比对各组件内部样式/相对锚点（字幕 13% 底、波形 calc(13%-31px)、徽标 top17/right18）。
3. **子像素字体渲染差异**（浏览器 vs Qt）不可消除，属于可接受范围；只对齐字号/字重/颜色/间距。
4. OCR 对图标的识别不可靠，用 PIL 采样判定。

### 修复结果（✅ 全部通过）

- ✅ **#1 视频标题去扩展名**：标题栏保留 `fileName()` 原名；画面内标题改 `QFileInfo(path).completeBaseName()`（demo 态直接去 `.mp4`）。并排比对两侧一致「航拍中国 第三季 第01集」。
- ✅ **#2 选项卡图标**：`buildLeftRail` 内加 `syncTabIcons` lambda（`icon("list"/"history", checked? accent(#7868ff) : kMuted, 15)` + `setIconSize(15,15)`），并挂到两个 tab 的 `toggled`（注意 tab 需先 `setCheckable(true)`；`QButtonGroup` 互斥保证单选）。像素验证历史 tab 左缘出现图标（136 像素）；激活态文字+图标均为 accent 色。
- ✅ **#3 控制条布局**：先从参考 HTML `05_Single_HTML_Frontend_Reference.html` 1050-1062 行核对真实标记——参考**右组**确有 `#trackButton`（`<use href="#i-subtitle"/>`），此前 OCR 漏读导致误判"参考无字幕轨按钮"。修复：`m_btnTrack` 图标 `monitor`→`subtitle`，从 `ll->addWidget(m_btnTrack)` 移除，改插到右组 `m_volume` 与 `m_btnSettings` 之间。左组=4 按钮、右组=倍速/音量/字幕轨/设置/全屏，并排一致。
- ✅ **#4 AB 字号**：`m_btnAb` 样式表补 `font-size:12px;font-weight:700`（参考 AB `<span style="font-weight:700;font-size:12px">`）。字形高 11px→9px（参考 8px，1px 属 Qt/浏览器子像素差异，可接受）。
- ✅ 验证闭环：`tools/build_ui.ps1 build` 通过 → `tools/run_snap.ps1` 出 `out/ui-snap/round5_fixed.png` → `make_compare.py`/`compare_regions.py` 重建并排 → PIL 像素采样（标题文本、tab 图标、AB 字形高、左/右组按钮数）+ 放大图目检全通过。

> 本轮一个关键纠偏：**不得只依赖 OCR/描述判断按钮有无**——参考稿右组的「字幕轨」按钮曾因 OCR 漏读被误判不存在。凡涉及控件有无/图标归属，必须回到 `05_Single_HTML_Frontend_Reference.html` 源码核对 `<button>` 标记。
